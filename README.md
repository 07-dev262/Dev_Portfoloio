# Dev Jeswani — Personal Portfolio Website

A clean, modern, and high-performance personal portfolio website engineered for **Dev Jeswani**, student of **M.Tech Integrated in Information Technology at IIPS DAVV, Indore**.

---

## 🌟 Highlights & Features

- **Side-by-Side Hero Section**: Introduces Dev with an eye-catching framed portrait card, dynamic typewriter subtitle, quick CTA buttons, and interactive tech badges.
- **Not "Vibe Coded"**: Built with clean semantic HTML5, modular CSS design system, and lightweight vanilla JavaScript. No messy dependencies, no bloated frameworks, zero lag.
- **Projects Showcase**:
  1. **Smart India Hackathon (SIH)**: Farmer Crop Procurement Web Platform with direct bidding, MSP transparency, and mobile optimization.
  2. **Academic Notes Sharing & Upload Hub**: Collaborative platform for peer-to-peer university note sharing.
  3. **Python Tkinter Desktop Calculator**: Cross-platform desktop application with precision evaluation and exception handling.
- **Full Interactive Modals**: Clicking *"View Details"* on any project opens an in-depth modal covering the challenge, solution, capabilities, and tech stack.
- **Interactive Tech Stack Grid**: Structured categorization of Python, C, C++, Frontend Web (HTML5/CSS3/JavaScript), and dev tools.
- **Dark & Light Mode**: Seamless theme switching with local storage persistence.
- **Contact Hub**:
  - Direct 1-click clipboard copy for `devjeswani1@gmail.com`.
  - Functional contact form that routes messages directly to your email client.
  - Social badges for LinkedIn (`linkedin.com/in/devjeswani`) and GitHub (`github.com/devjeswani`).
- **100% Offline Capable**: Custom standalone vector graphics (SVGs) for avatar and project cards; works anytime even without internet access.
